# jfc-h4l

The H→4ℓ exercise of the
[JFC tutorial](https://github.com/jfc-mit/jfc-tutorial-nrp-clariphy) as a
[`jfc`](../jfc) analysis: a Higgs boson mass and signal-strength measurement in
the four-lepton channel, on the tutorial's ntuples.

| File            | What it is                                                             |
| --------------- | ---------------------------------------------------------------------- |
| `analysis.toml` | The exercise's prompt, papers and ntuplizer by commit, and its ntuples |

How to run it and what the keys mean: [`workflows/jfc`](../jfc/README.md#running).
