# hmm

The CMS H→µµ search with the full Run 2 dataset as an
[`agentic-analysis`](../..) analysis, at full scale: the analysis of
arXiv:2009.04363 done anew with the JFC methodology on the Ultra-Legacy
NanoAOD, read through Purdue's XCache.

| File            | What it is                                                                                              |
| --------------- | ------------------------------------------------------------------------------------------------------- |
| `analysis.toml` | The analysis's name and type; its prompt and files are those beside it                                  |
| `prompt.md`     | The physics goal, the publications to compare with, and the resources it may use                        |
| `datasets.yaml` | Its data and simulation by period, with the signals' cross sections, the luminosities and their sources |

How to run it and what the keys mean: [`workflows/agentic-analysis`](../../README.md).
